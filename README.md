# Daniel Morales

Personal profile of Daniel Alberto Maldonado Morales, a Full Stack Developer based in Guadalajara. The site is a dark, terminal-style SPA with About, Background, Projects, and Contact, available in English and Spanish.

Built with React Router 8 (SPA mode), React 19, TypeScript, i18next, and Zustand. Styling is custom CSS only.

## Run locally

The UI runs through Docker Compose on port `5173`.

```bash
docker compose up --build
```

Then open [http://localhost:5173](http://localhost:5173).

From `ui/` you can also use `pnpm install` and `pnpm dev` if you already have Node and pnpm on the host.
